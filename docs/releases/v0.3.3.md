# 番渡 Fandu v0.3.3

A local-first anime and media tracker with customizable themes and automatic saving.

这是番渡的首次公开整理版本：简洁的作品收藏与进度管理，支持评分笔记、自定义列表／标签／系列、多来源查找、五套预设与自定义主题色，以及自动保存、备份快照和完整迁移。

## 下载

- **Mac Apple Silicon · macOS 13+**：下载 `番渡-0.3.3-arm64.dmg`，拖入“应用程序”；或选择 `番渡-0.3.3-arm64-mac.zip`。
- **Windows x64 / ARM64 · 64 位 Windows 10+**：下载 `番渡 Setup 0.3.3.exe`，同一安装器包含两种架构。
- `SHA256SUMS.txt`：安装文件完整性校验清单。
- `LICENSE`：MIT 许可证。依赖和第三方资料另遵循各自许可。
- GitHub 自动生成的 Source code 文件仅为源码，不是安装包。

## 使用前请留意

- **安装包未签名／未公证**，系统可能显示警告；请确认下载来源，不要关闭系统安全防护。
- Mac 版已有本机验证；**Windows 安装包已生成，但尚未原生实测**。
- 暂无 Intel Mac 或 Linux 包，也没有自动更新。升级前请在设置的“备份”中导出完整迁移包。
- 网页版收藏不会自动转到桌面版，请导出再导入；未提交草稿与浏览器恢复记录不在迁移包内。
- 联网资料来源可能限流或不可用；本软件不提供视频播放、影视下载、账号或云同步。

详细使用方式见仓库 README。遇到问题请通过 Issues 反馈版本、平台和复现步骤，注意遮盖个人数据。
